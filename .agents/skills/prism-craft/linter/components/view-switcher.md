# View Switcher

Source: [https://ds.nutanix.design/components/view-switcher](https://ds.nutanix.design/components/view-switcher)
React: `ViewSwitcher`

---

## Overview

The View Switcher component allows users to toggle between different, closely related views or formats of similar content within the same visual block on the screen (e.g. switching between a Card view and a List view).

---

## Usage Guidelines

- **Mutually Exclusive**: Only one formatting or content view is shown at a time.
- **Purpose**: Ideal for toggling between alternate displays of data, narrowing content groups, or shifting between dense formats.

---

## Anatomy & Variants

- **Anatomy**: Composed of a container, view option buttons, and a high-contrast active indicator bubble.
- **Variants**: Supports text-based tabs or icon-based option buttons.

---

## Keyboard Navigation

- Press `[Tab]` to focus on the active view option.
- Use horizontal arrow keys `[←/→]` to instantly navigate and select between different views.
- Press `[Tab]` to navigate focus out to the next interactive page component.
